# Mac Terminal Index

macOS Terminal komutlarını konuya göre indeksleyen, aratan ve tek tıkla kopyalatan statik site.

## Yerelde çalıştırma

```bash
git clone git@github.com:yetkinbasarir/utility.git
cd utility
python3 -m http.server 8000
```

Ardından `http://localhost:8000` açın.

## GitHub Pages

GitHub'da **Settings → Pages → Deploy from a branch → main / root** seçin.

Komutlar `data/commands.json` içindedir; yeni içerik eklemek için yalnızca bu dosyayı düzenlemek yeterlidir.
